How this is worked out

These figures are estimates. Thread use varies with how you stitch, so treat the skeins as a guide.

Print the pattern

The file has the finished picture, the thread key, the shopping list and the chart. Open it from your downloads and choose Print.

The spare fabric is only a suggestion. It is drawn on the size page and counted in the fabric to buy.

Save the project file too?

The pattern is saved. The project file is the design itself. With it you can open the design here again, change it, or tick stitches off on screen as you sew.

Keep the current design?

Starting something new replaces the design on screen. Save the project file first if you want to keep it.

Tidy stray stitches

A stray stitch is a single stitch with no stitch of the same colour beside it. Tidying changes it to the colour most common around it. Single stitches on bare fabric are left alone.

A small detail made of one stitch, such as an eye, counts as stray too. Look over the design afterwards. Undo brings everything back.
